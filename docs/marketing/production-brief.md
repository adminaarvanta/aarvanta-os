# Aarvanta AI-story ads — production brief

Series-wide rules. Ad #1 checklist at the bottom. Companion: [series-overview.md](./series-overview.md).

---

## Brand

| Token | Value | Use |
| --- | --- | --- |
| Navy | `#1a2f59` | Structure, voids, end-card field |
| Gold | `#a8894f` / `#b3965d` | CTA, caption **highlights**, waveform accents |
| Foreground | `#0e1522` on light / `#f4f7fb` on dark | Body captions depending on plate |
| Surfaces | `#f5f7fa` / white | Prefer **light OS UI** in product proof for readability |
| Accent avoid | Generic purple neon, cyan-only “AI” looks unless product UI already uses them |

**Wordmarks:** Aarvanta · AI Team (product surface name). Prefer “AI Team” over old “workforce” wording in VO/captions.

**Tone:** Founder-serious, systems-smart. No hype coins, no fear porn, no fake metrics.

---

## Deliverable specs

| Spec | Value |
| --- | --- |
| Aspect | 9:16 |
| Resolution | 1080×1920 |
| Length | 55–65s (Ad #1 target 60s) |
| Frame rate | 30fps (24fps OK if cinematic GEN matches) |
| Captions | Burned-in + separate `.srt` for platform re-upload |
| Safe margins | ≥120px from top/bottom for platform UI |
| Export | H.264 mp4, high bitrate (≥12 Mbps), AAC audio |

---

## Suggested tool stack (flexible)

| Job | Options |
| --- | --- |
| GEN B-roll / AI character | Runway / Kling / Luma / equivalent — consistent seed/character ref |
| Human plates | Controlled live shoot **or** licensed stock that matches casting |
| Edit + captions | CapCut / Premiere / DaVinci — kinetic lower-thirds |
| UI capture | QuickTime / OBS + phone bezel in edit |
| VO | Founder mic or ElevenLabs-class clone **with consent** |
| Music | Licensed bed (Epidemic / Artlist / etc.) — low vocals |

Pick tools you already license; fidelity of **face consistency** and **UI truth** matter more than which generator.

---

## Do / Don’t

**Do**

- Show real Aarvanta product surfaces for proof  
- Keep captions short enough to read mute  
- Hold CTA ≥3s  
- Keep generative-AI disclaimer visible  
- Match navy/gold brand hierarchy  

**Don’t**

- Invent course pricing or fake ROI (“make $10k in a week”)  
- Clone competitors’ characters, salon plots, or “TRY ME $20” punches  
- Use unreadable micro-UI; crop to meaningful regions  
- Overload end card with QR + five links + hashtags  

---

## Legal / compliance

**Always-on or final-card disclaimer (min):**

> Dramatized scenes may use generative AI. Results vary. Aarvanta does not guarantee specific business outcomes.

Also:

- No competitor trademarks as “enemies” in logo chaos unless cleared  
- Blur or replace real customer PII in UI recordings  
- Voice clone / likeness: written consent
